# Козёл 3.0 — объединённый проект, предварительная сборка

Основа: `kozel-main (2)(1).zip`. Наложены все файлы из `kozel-v3-stages1-6-voice.zip` и затем более позднее исправление `kozel-menu-height-fix.zip`.

**Не считать готовой к публикации:** полноценные интеграционные тесты и работа радио/голосового чата на реальных устройствах не подтверждены. Для радио необходимы разрешённые потоки, для голоса может понадобиться TURN.

Колода остаётся **36 карт**. Неверный патч с 32 картами исключён. Ошибка отображения 21 карты после автохода ещё требует воспроизведения и диагностики.

Изменения накладываются поверх исходной версии и могут отличаться от текущей `main` на GitHub. Перед объединением с `main` обязательно сравнить код.
