# Отчёт об исправлениях по PDF-плану

| Пункт | Изменения в исходниках | Что ещё проверить |
|---|---|---|
| 01. Безопасность | Переменные окружения, проверка JWT и владельца профиля, права по ID, TLS, ограничения частоты входа, исключение секретов и данных пользователей | Смена действующих секретов, настройка доверенных ID, проверка истории Git и боевой среды |
| 02. Сборка | Отдельный пакет game-core, правильный экспорт, настоящие команды сборки, чистые исходники, удалён некорректный lock-файл, добавлена безопасная standalone-сборка | Установка pnpm, получение нового lock-файла, сборка клиента/сервера |
| 03. Таймер | Общий `applyTurn`, полный сброс и добор, защита версии хода, бот и таймер используют `automaticTurn` | Реальный таймер и разрывы сети |
| 04. Ходы | Запрещены пустая атака и недопустимые наборы, подсказки используют тот же движок, корректный остаток руки | Подтвердить оговорённый в README вариант пустого сброса |
| 05. Интерфейс | Совпадающие идентификаторы мастей, проверка выбранной комбинации, отображение 4 мест, состояния подключения, корректные параметры админ-панели | Браузер/телефон |
| 06. Комнаты | Фиксированные места, уникальные DEV и ID комнат, переподключение, ограничения размера, членство, проверенные приглашения, удаление неактивных комнат | Интеграционные тесты Socket.IO |
| 07. Друзья | SQL alias friendRequests, проверка заявки, блокировки строк и транзакции, регистрация с SERIAL, ошибки БД возвращаются клиенту | Миграция/реальная PostgreSQL |
| 08. Статистика | Ветка штатного завершения, все игроки по сторонам A/B, транзакция и уникальный ID матча, повтор записи при ошибке; без оптимистического начисления клиентом | DB-интеграция и полный сетевой матч |
| 09. Тесты | 12 тестов ядра, 200 симуляций конов, DB/HTTP/Socket.IO тесты, CI GitHub Actions | Интеграционные тесты пока не выполнены |

Не включены в архив: действующие секреты, исходная `users.json`, старый `server-dist`, дублированные JS/типовые файлы и старые lock-файлы. Для запуска потребуется новый `.env`, новая установка зависимостей и новая сборка. Исходный архив сохранён без изменений.
