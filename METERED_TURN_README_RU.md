# Подключение Metered TURN к «Козёл 3.1»

Файл: `apps/server/src/index.ts` (замена соответствующего серверного файла).

В ONREZA **только для kozel-server** после загрузки исправления добавь:

- `TURN_URLS` — URL из Metered через запятую, без пробелов. Например: `turn:global.relay.metered.ca:80,turn:global.relay.metered.ca:80?transport=tcp,turn:global.relay.metered.ca:443,turns:global.relay.metered.ca:443?transport=tcp`
- `TURN_USERNAME` — имя пользователя из Metered, сохрани приватно.
- `TURN_PASSWORD` — пароль из Metered, сохрани приватно.

`TURN_SHARED_SECRET` не требуется для Metered и не должен использоваться вместо пароля.

После внедрения и деплоя сервер будет возвращать ICE-настройки авторизованным игрокам через `GET /api/voice/ice`. Клиент `VoiceChat.tsx` уже вызывает эту точку.

ВНИМАНИЕ: даже если пароль хранится в ONREZA, статические TURN-данные передаются каждому авторизованному браузеру через `/api/voice/ice`; их можно извлечь из сетевых запросов. Этот способ подходит для ограниченного теста, но перед открытым публичным запуском рекомендуется настроить краткоживущие credentials через API провайдера, ограничение трафика и ротацию учётных данных.

Не публикуй пароль/имя пользователя в GitHub, в скриншотах или в этом ZIP.

Не проверено в работающем ONREZA окружении; перед слиянием выполнить GitHub Actions и отдельно проверить подключение по 2 телефонам.
