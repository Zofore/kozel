Основа: kozel-main (2)(1).zip + последовательные пакеты этапов 1–5 + этап 6.

Этап 6 — голосовой чат (НОВОЕ):
  apps/client/src/VoiceChat.tsx             новый клиентский WebRTC-компонент
  apps/client/src/voice.css                новые стили управления голосом
  apps/client/src/App.tsx                  монтирование голосового чата в игровой комнате
  apps/server/src/index.ts                 сигнализация Socket.IO и защищённая выдача ICE конфигурации
  apps/server/.env.example                 пример настройки TURN-сервера
  apps/client/tests/server.integration.test.mjs  тесты запретов доступа к голосу

Возможности:
  - добровольное подключение; микрофон выключен до нажатия игрока;
  - 1×1: голос для всех; 2×2: Все / Только команда;
  - отключение собственного микрофона, звука отдельных игроков, громкость;
  - автоматическое освобождение микрофона при выходе и обрыве соединения;
  - сервер только передаёт сигналы WebRTC (не аудио);
  - голосовые сигналы запрещены вне комнаты и между недопустимыми сторонами;
  - минимальный дополнительный интерфейс в исходных цветах.

Сеть:
  - Для большинства сетей используется STUN, но в мобильных сетях, за строгими
    NAT или фаерволами понадобится собственный TURN-сервер (например, coturn).
  - В ONREZA kozel-server можно настроить TURN_URLS (список через запятую)
    и TURN_SHARED_SECRET (секрет coturn REST credentials длиной >= 32).
  - Сервер выдаёт игроку короткоживущие TURN-учётные данные по JWT.
    НИКОГДА не храните постоянный TURN-пароль в VITE_* переменных.
  - Сайт должен открываться по HTTPS, у игрока должен быть разрешён микрофон.

ПРОВЕРКА ПЕРЕД УСТАНОВКОЙ:
  1. Загрузить файлы в ОТДЕЛЬНУЮ ветку GitHub на базе актуальной main.
  2. Сравнить App.tsx и index.ts с главной веткой — они могли измениться с момента архива.
  3. Выполнить GitHub Actions: сборка, regression, integration.
  4. Провести тест 1×1 и 2×2 на двух телефонах в разных сетях, проверить режим команды,
     запрет подключения постороннего, выключение микрофона при выходе.
  5. При успешных тестах объединить ветку и разворачивать в ONREZA.
