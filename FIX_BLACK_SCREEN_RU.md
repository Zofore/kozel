# Козёл 3.1 — исправление чёрного экрана

## Исправлено

В `apps/client/src/Menu.tsx` переменная состояния `isMobile` объявлялась **после** вызова `useLayoutEffect`, в массиве зависимостей которого она уже использовалась. Это вызывало ошибку JavaScript `ReferenceError: Cannot access ... before initialization`, из-за чего приложение отображало пустой/тёмный экран.

Объявление `isMobile` перемещено выше эффекта, без изменения оформления или функциональности меню.

## Состав

Полный исходный проект из последнего объединённого архива «Козёл 3.1»: интерфейс, сервер, игра и тесты. Сохранены настройки адаптации меню без прокрутки, раздельные контролы радио и фоновой музыки, мобильное расположение голосового чата, 36 карт в колоде.

## Установка и безопасность

Сначала загрузите изменённый код в **отдельную ветку**, выполните CI, затем проверьте работу в тестовом развёртывании. Не перезаписывайте продакшн без проверки. Если сервер не менялся, достаточно заменить на GitHub файл `apps/client/src/Menu.tsx`, а не переписывать весь проект.

## Ограничения

Целостность ZIP и статическая проверка TSX выполнены. Полная сборка зависимостей и тестирование в браузере/на ONREZA в этой среде не выполнены. Работа радио требует действующих HTTPS URL потоков в переменных окружения клиента; WebRTC/TURN и автоход в реальной игре остаются предметом отдельной проверки.
