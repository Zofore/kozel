# Козёл 3.1 — единый ZIP с правками интерфейса

Основа — ранее объединённый проект v3.0 (этапы 1–6). Последние изменения:

- `apps/client/src/Menu.tsx`: меню без прокрутки, с автоматическим масштабированием панели по высоте экрана.
- `apps/client/src/MenuBackground.tsx`: кнопка фоновой музыки отделена от блока радио; на широких экранах справа от радио, на узких — в левом верхнем углу. Кнопка не меняет громкость радио.
- `apps/client/src/RadioPlayer.tsx` и `radio.css`: радио остаётся самостоятельным блоком внизу слева.

Важно: архив включает **полный исходный проект** из ранее предоставленной предварительной сборки, а не изменения из текущей GitHub main после слияния. Сначала сравнить ветки и проверить сборку, не заливать сразу поверх main.

Не входит: устранение ошибки «21 карта после автохода», подключение потоков радио, подтверждение работоспособности WebRTC-голоса. Колода остаётся на 36 картах, патч на 32 карты не применялся.

- `apps/client/src/VoiceChat.tsx` и `voice.css`: на мобильных голосовой чат свёрнут до отдельной кнопки справа (не перекрывает радио снизу слева и кнопку фоновой музыки сверху слева). При открытии показывает настройки, со своей прокруткой только внутри панели при нехватке места. На ПК остаётся обычная панель голоса.
